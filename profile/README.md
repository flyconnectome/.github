# Fly Connectome

Tools to analyse connectomes, built on the [natverse](https://natverse.org) (R) and [navis](https://github.com/navis-org/navis) (Python). Full overview: [flyconnectome.github.io/tools](https://flyconnectome.github.io/tools/).

## Knowledge

- [drosophila_neurotransmitters](https://github.com/flyconnectome/drosophila_neurotransmitters): neurotransmitter ground truth for *Drosophila* cell types
- [drosophila_neuropeptides](https://github.com/flyconnectome/drosophila_neuropeptides): curated data on about 50 neuropeptides
- [drosophila_cell_functions](https://github.com/wilson-lab/drosophila_cell_functions): literature-backed observations on neuronal cell types
- [flywire_annotations](https://github.com/flyconnectome/flywire_annotations): cell annotations for FlyWire
- [nblast-scoremats](https://github.com/flyconnectome/nblast-scoremats): NBLAST scoring matrices

## Analysis

- [cocoa](https://github.com/flyconnectome/cocoa): comparative connectomics in Python
- [bigclust2](https://github.com/flyconnectome/bigclust2): explore clusterings of connectome data
- [acdc_py](https://github.com/flyconnectome/acdc_py): AC/DC neuron matching in Python

## Dataset access

- R: [crantr](https://github.com/flyconnectome/crantr) · [fancr](https://github.com/flyconnectome/fancr) · [seatabler](https://github.com/flyconnectome/seatabler)
- Python: [dvid_tools](https://github.com/flyconnectome/dvid_tools)

## AI agents

- [connectome-agents](https://github.com/wilson-lab/connectome-agents): AI skills for connectome analysis
- [natmcp](https://github.com/flyconnectome/natmcp): gives coding agents current natverse knowledge
